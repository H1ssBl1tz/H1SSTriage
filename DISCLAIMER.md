# Disclaimer

H1SSTriage é exclusivamente defensivo e deve ser usado apenas em sistemas próprios ou formalmente autorizados.

É uma ferramenta de live response/triage. Não é antivírus, EDR, aquisição forense bit a bit, ferramenta forensically sterile nem garantia de ausência de comprometimento. Um host comprometido pode ocultar ou adulterar dados por rootkit, kernel tampering, API hooking, WMI tampering ou alteração posterior dos outputs.

A coleta não altera persistências, processos, Defender ou firewall. Ela cria arquivos de relatório e produz atividade observável. O menu contém exclusão confirmada de pastas de relatório diretas; reparse points e alvos não comprovadamente seguros são recusados.
